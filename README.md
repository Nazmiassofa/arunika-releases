# Arunika Billiard POS — Rilis Android

Halaman unduhan aplikasi Android Arunika Billiard POS.

## Unduh

**[⬇️ Rilis terbaru](https://github.com/Nazmiassofa/arunika-releases/releases/latest)**: buka halaman ini, lalu unduh file `.apk` di bagian *Assets*.

## Cara pasang

1. Unduh file `arunika-vX.Y-release.apk` dari halaman rilis di HP atau tablet Android.
2. Buka file tersebut. Bila diminta, izinkan **Instal aplikasi tidak dikenal** untuk browser atau file manager yang dipakai.
3. Ketuk **Instal**. Bila versi lama sudah terpasang, aplikasi diperbarui tanpa menghapus data login.

## Cek keaslian file (opsional)

Setiap rilis menyertakan file `.sha256`. Di komputer:

```sh
sha256sum -c arunika-vX.Y-release.apk.sha256
```

Hasil `OK` berarti file utuh dan sama dengan yang dirilis.
